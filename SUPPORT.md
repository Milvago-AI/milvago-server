# Getting help

| You want to… | Go to |
|---|---|
| Ask a question, share a setup, talk with other users | [Milvago AI Discord](https://discord.gg/69JPyVjqv) |
| Report a bug you can reproduce | [a bug report](https://github.com/Milvago-AI/milvago-server/issues/new?template=bug_report.yml) |
| Propose a feature | [a feature request](https://github.com/Milvago-AI/milvago-server/issues/new?template=feature_request.yml) |
| Report a vulnerability | **not** an issue — follow [SECURITY.md](SECURITY.md) |
| Enterprise edition, licensing, commercial support | [www.milvago.ai](https://www.milvago.ai) |

Before opening an issue, read [INSTALL.md](INSTALL.md) and search the existing issues. A report
that names the version or commit, the steps and the observed result gets an answer much faster
than one that describes the expected result only.

Community support is best effort, from maintainers and users alike. Everyone taking part is
bound by the [Code of Conduct](CODE_OF_CONDUCT.md).
