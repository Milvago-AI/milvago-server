# Logos éditeurs / Vendor logos

Déposez ici les SVG officiels des éditeurs, nommés par slug en minuscules : `openai.svg`, `anthropic.svg`, `google.svg`, `microsoft.svg`, `perplexity.svg`, `mistral.svg`, `chrome.svg`, `firefox.svg`, `edge.svg`, `cursor.svg`.
Respectez les règles de marque de chaque éditeur (couleurs, marges, usage) avant publication.
Aucun fichier n'est fourni par défaut et rien n'est téléchargé depuis Internet : en l'absence d'un SVG, la console affiche un monogramme coloré à la place.
Ajouter ou remplacer un fichier ici suffit — aucune configuration ni redéploiement du code n'est nécessaire pour qu'il apparaisse dans la cartographie.
